Components

Commons user interface components in action. The style guide shows how things look, this page shows how commons components behave and how applications use them.

Dialogs

Variants and sizes

Modal dialogs are created by ModalDialog, which shows the Bootstrap modal component with its standard markup and events.

ModalDialog.show({ title: "Dialog title", body: $("<p>").text("Dialog message"), variant: "danger", size: "lg", buttons: [ { label: $.t("common.form.cancel") }, { label: $.t("common.form.delete"), className: "btn-danger", action: (dialog) => remove(dialog) } ] });

Confirmation

ModalDialog.confirm asks the user to confirm an action and returns a promise resolved with the choice, UIUtils.confirmDialog shows the commons confirmation dialog.

ModalDialog.confirm({ title: "Delete", body: "Do you really want to delete it?", variant: "danger", confirmLabel: $.t("common.form.delete") }).then((confirmed) => { ... }); UIUtils.confirmDialog("Do you really want to do it?", "default", () => { ... });

Notifications

Messages

Notifications are shown at the top of the page by Messages.

Messages.addMessage({ type: Messages.TYPE_SUCCESS, message: "Changes have been saved." });

Form validation

Validators

Inputs declare their validators (data-validator) and ValidatorsManager binds them; the view shows the validation state of each field.

// <input class="form-control" type="password" minLength="8" data-validator="required minLength" // data-validator-event="keyup"> ValidatorsManager.bindValidators(this.$el.find("form"));

Selectize

Single value

this.$el.find("#selectizeExample").selectize({ create: true });

Multiple values

this.$el.find("#selectizePillExample").selectize({ create: true, maxItems: 3 });

Backgrid

Grid with paginator and filter

Sortable columns, ThemeablePaginator and a client side filter with the markup of ThemeableServerSideFilter (which filters collections on the server).

const grid = new Backgrid.Grid({ className: "backgrid table", columns, collection }), paginator = new Backgrid.Extension.ThemeablePaginator({ collection, windowSize: 3 }), filter = new Backgrid.Extension.ThemeableServerSideFilter({ collection, name: "_queryFilter" }); this.$el.find("#grid").append(filter.render().el, grid.render().el, paginator.render().el);

Spinner

Loading spinner

Displayed automatically during REST calls (unless the call is made with suppressSpinner). It can be also controlled with SpinnerManager.

SpinnerManager.showSpinner(); // ... when the work is done SpinnerManager.hideSpinner();
